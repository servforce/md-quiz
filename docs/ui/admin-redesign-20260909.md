## 实现边界

- 继续使用 Alpine SPA、现有模块和 Tailwind utility，没有替换前端框架或引入在线字体、运行时 CDN。
- 页面几何与响应式直接写入页面模板，共享 CSS 只承载共享机制与皮肤。
- 新增管理接口：任务总览、职位草稿预览；扩展测验公开状态筛选、日志查询和图片预览。参数与响应见 [REST API 约定](../reference/api.md)。没有数据库 schema 迁移。
- 管理端构建使用 `npm --prefix static run build:admin-css`，只生成管理样式。构建脚本默认无参数仍支持完整构建；`--target public` 与 `--target all` 可显式选择范围。
- 候选人端源码、样式包和共享运行时与本轮实施前归档逐文件校验，避免管理样式构建改写冻结范围。

## 验收记录

接口验证使用独立 PostgreSQL 数据库及真实 FastAPI TestClient；新增测试未替换业务模块为 mock。浏览器使用本地独立 API，无 Worker、Scheduler、外部模型或短信调用。展示的未配置告警是演示环境事实。

- 新增与相关前端/API 套件：41 项通过，涵盖总览时间边界与全量计数、软删除历史、分页前筛选、日志编号/操作者字面查询、草稿渲染不写入、四种图片内容验证、鉴权与错误状态、同步摘要和评分模式。
- 既有管理端接口回归：40 项通过。一次补跑发现旧测试期望未包含错误末尾测验编号；改前路由已经返回该编号，核对归档后修正断言并单独复验，没有修改邀约创建行为。
- 测验 25 条数据实测分为 20 + 5，公开邀约筛选得到对应全量结果；邀约在 1600×1150 视口可完整显示 8 条记录，390px 宽度无整页横向溢出。
- 分析页实测最右 100 分桶在视口内；点击 90–99 分桶仅显示 92 分答卷。Traits 四组维度一直可见，权重开关不改变结果，全宽评价可返回回放。
- 职位实测继续编辑、放弃、保存后切换、无效表单保存失败仍保留原草稿、预览正文修改后及时更新、Git 只读。候选人评价取消与保存、图片加载及 Escape 焦点恢复通过。
- 总览三项计数与 API 一致；日志翻页、编号搜索和操作者/分类联动通过；状态标签方向键与焦点、未保存输入保留、MCP 配置选择与复制通过。
- 全局导航实测刷新保留滚动位置、浏览器后退恢复列表位置、快速连续导航最终保留最后选择的页面，没有旧页面片段覆盖。通过“邀约 → 答卷 → 候选人 → 返回答卷 → 返回邀约”验证来源链恢复；将浏览器中的日志片段路径临时指向不存在的本地文件，验证真实 404 后清空旧内容、显示错误与重新加载按钮，恢复路径后可成功重载。

## 补充排查：内网 HTTP 加载卡死（2026-09-10）

用户通过内网 HTTP 地址访问时，新增导航代码在 `rememberAdminScroll()` 中调用 `crypto.randomUUID()`，浏览器报 `TypeError: crypto.randomUUID is not a function`。该异常发生在登录接口请求之前，且启动流程原先没有捕获异常、关闭遮罩，因此一直显示“后台正在加载”。9 月 9 日浏览器验收使用 loopback 地址，其安全上下文规则与普通内网 IP 不同，遗漏了这一访问条件。

现已将三处历史条目创建统一到适用于 HTTP 的随机标识生成方法，并补齐启动错误展示和重新加载入口。在用户的内网地址上实测，`isSecureContext=false`、`crypto.randomUUID` 仍不可用时，页面可完成初始化并显示登录表单。新增真实浏览器回归覆盖 HTTP 历史条目、分页、后退恢复及启动 API 404；连同既有页面模块检查共 5 项通过。候选人端及共享资源的冻结校验通过。本次前端修复不依赖后端重启。

证据见 [排查记录](../../output/admin-http-loading-20260910/diagnosis.json) 与 [内网地址修复后截图](../../output/admin-http-loading-20260910/lan-login-after.png)。
