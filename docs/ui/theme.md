# UI 主题覆盖

本文件是项目内 UI 配色与视觉语义的事实来源，供 [static-ui skill](../../skills/static-ui/SKILL.md) 优先读取。
布局和 utility 写法约束见 [Utility 落地规则](utility-authoring.md)；本文件只描述当前实现已经落地的主题与布局事实。

- 适用范围：`static/admin/`、`static/public/` 及共享静态样式。
- 当前不是“全站统一单一深色主题”。
- 当前主题基线是：
  - 后台：贴边导航 + 浅底实色面板 + 蓝绿品牌强调
  - 候选人端：深色答题壳层 + 蓝绿高亮与进度反馈

## 共享品牌事实

- 主品牌蓝：`#2563eb`
- 主品牌绿：`#16a34a` / `#22c55e`
- 品牌观感仍是“蓝色 + 绿色”
- 品牌色主要用于主操作、激活态、进度条、图标和浅色背景，不用于整页大面积实底

## 后台主题

后台以 `static/assets/css/admin/theme.css` 和 `static/admin/index.html` 为准。

### 总体风格

- 明亮、克制的浅色工作台，使用贴边全高导航和连续顶栏
- 页面底层保留低饱和度的蓝绿渐变，去掉装饰光晕
- 主要容器使用近白实色面板、浅蓝灰边框和轻微阴影，不使用玻璃模糊

### 核心颜色

- 页面背景：`oklch(0.964 0.017 255)` → `oklch(0.974 0.007 255)` → `oklch(0.976 0.012 160)`
- 主文字：`#10233f`
- 面板背景：`--admin-panel: oklch(0.998 0.002 255)`
- 导航与顶栏：`--admin-panel-strong: oklch(0.992 0.004 255)`
- 边框：`--admin-border: oklch(0.916 0.014 255)`
- 主按钮：`bg-blue-600 text-white`
- 主导航激活：浅蓝背景、蓝色文字和细边框，使用 `aria-current="page"` 标识
- 强调辅助色：`#16a34a`

### 组件基线

- 侧栏、头部、浮层维持近白实色表面与细分割线
- 非激活态导航使用柔和灰蓝文字与浅蓝 hover
- 系统状态使用后端 `overall_level` 映射中文文案与绿、黄、红状态色，未取得状态时显示“状态未知”
- 不要把后台整体改回深色卡片堆叠式控制台

### 导航与工作区

布局参考 [Scisaga/md-quiz](https://github.com/Scisaga/md-quiz/tree/3b2a3eb110480ccd1ee88808479a9bd7deffc050/static/admin) 的贴边工作台结构，保留本项目现有路由与业务能力。

- 整体不设置外层留白或最大宽度；桌面侧栏宽 232px，折叠为 72px，偏好存于浏览器本地存储
- 顶栏高 72px，滚动时保留标题、系统状态和用户菜单；详情页显示对象名称，面包屑返回来源页面，列表筛选、页码和滚动位置随导航保留
- 768px 以下隐藏侧栏，使用带文字的顶部图标导航；导航可横向滚动，页内切换与顶栏一起保留
- 768–1279px 保留侧栏，通过页内标签切换列表与辅助面板；1280px 起显示双栏
- 工作区内边距：手机 12px、640px 起 16px、1280px 起 20px；面板间距 16px
- 常规列表双栏采用弹性主列与 22rem 辅助列，1536px 起辅助列 24rem；候选人档案和答卷详情按阅读内容分配比例列宽，长评价使用页面自然滚动，并可展开到全宽
- 面板使用 `admin-surface` 共享皮肤；模板统一 `rounded-xl p-4 sm:p-5`，分区面板由各分区承担内边距
- 辅助面板吸顶位置为顶栏下方 20px，最大高度为剩余视口，短面板按内容高度展示；长表单在面板正文内滚动
- 职位列表在宽屏内独立滚动，编辑区保持自然页面高度
- 测验详情的内容、分析、版本历史使用全宽任务标签；分析在窄容器内改为逐段纵向展示，保留所有分桶
- 系统状态在每日统计和接入配置之间切换；MCP 按所选客户端显示配置；总览提供待处理、近期完成和失败任务入口，默认首页仍为测验列表
- 职位未保存修改确认与图片简历预览使用原生 dialog，支持 Escape、焦点限制与关闭后恢复焦点
- 页面几何与断点直接写入模板 utility；共享导航和滚动机制分别维护在 `shell.css` 与 `components.css`

## 候选人端主题

候选人端以 `static/public/index.html`、`static/public/views/*.html` 的模板 utility 为主，`static/assets/css/public/theme.css` 只提供辅助变量与基础渐变。

### 总体风格

- 深色答题壳层
- 蓝绿光晕背景
- 白字和浅灰辅助字
- 交互强调色集中在青绿进度、按钮和焦点态

### 核心颜色

- 页面主底：`bg-slate-950`
- 主文字：`text-white`
- 次文字：`text-slate-200 / text-slate-300 / text-slate-500`
- 卡片背景：`bg-white/5`、`bg-white/6`、`bg-slate-950/45`、`bg-slate-950/55`
- 卡片边框：`border-white/10`
- 主操作按钮：`bg-emerald-400 text-slate-950`
- 焦点 / 输入强调：`border-emerald-300/40`
- 进度与剩余时间：`teal / emerald`

### 说明

- 候选人端当前实际视觉是深色壳层优先，而不是复用后台的浅色面板
- 新增候选人端页面时，应优先延续现有深色答题体验，不要直接照搬后台浅色容器

## 状态色

- Danger：`rose`
- Warning：`amber`
- Info：`sky`

这些状态色继续保持语义独立，不和品牌蓝绿混用。

## 使用规则

- 新页面先判断属于后台还是候选人端，再继承对应壳层主题
- 品牌一致性来自蓝绿强调色，不来自“所有页面都必须同色底”
- 后台页面优先浅底白面板；候选人端优先深底高对比答题壳层
- 当 `skills/static-ui/SKILL.md` 的默认主题与当前实现冲突时，以本文件为准
